HACS e Nexo Hub no Home Assistant

Do Home Assistant recém-instalado até os circuitos do Nexo aparecendo nos painéis.

Resumo

1. Antes de começar 2. Instalar o HACS 3. Ativar o HACS 4. Instalar o Nexo Hub 5. Adicionar o sistema Nexo

O HACS é a loja de integrações da comunidade do Home Assistant. Ele não vem instalado: é preciso instalar uma vez, e depois ele baixa e atualiza integrações como a do Nexo Hub.

Os nomes de menu mudam um pouco entre versões do Home Assistant. Se algum passo não bater com a sua tela, a referência oficial é hacs.xyz/docs/use.

1. Antes de começar

  • Home Assistant já instalado e com o primeiro usuário criado (a tela de boas-vindas concluída).
  • Home Assistant com acesso à internet.
  • Uma conta no GitHub (gratuita). O HACS pede para vincular uma conta na ativação.
  • Saber o tipo da instalação: Configurações → Sistema → Sobre, linha "Método de instalação".
Método de instalaçãoComo instalar o HACS
Home Assistant OS ou SupervisedCaminho A (add-on Get HACS)
Container (Docker)Caminho B (comando dentro do contêiner)
Core (Python direto)Caminho C (comando na pasta de configuração)

2. Instalar o HACS

Caminho A: Home Assistant OS ou Supervised

  1. Abra Configurações → Add-ons → Loja de add-ons (em versões recentes o menu aparece como "Apps").
  2. No menu de três pontos, escolha Repositórios e adicione: https://github.com/hacs/addons
  3. Feche a janela, procure o add-on Get HACS e clique em Instalar.
  4. Clique em Iniciar e abra a aba Registro: ele avisa quando terminou de baixar.
  5. Reinicie o Home Assistant: Configurações → Sistema → botão de energia → Reiniciar.

Caminho B: Container (Docker)

No computador onde o Docker roda:

docker exec -it homeassistant bash
wget -O - https://get.hacs.xyz | bash -
exit
docker restart homeassistant

Troque homeassistant pelo nome do seu contêiner, se for outro (docker ps mostra).

Caminho C: Core

Com o usuário que roda o Home Assistant, dentro da pasta de configuração (onde fica o configuration.yaml):

wget -O - https://get.hacs.xyz | bash -

Depois reinicie o Home Assistant.

Nos três caminhos o resultado é o mesmo: a pasta custom_components/hacs dentro da configuração.

3. Ativar o HACS

  1. Limpe o cache do navegador ou recarregue a página com Ctrl + F5. Sem isso o HACS pode não aparecer na busca.
  2. Abra Configurações → Dispositivos e serviços → Adicionar integração.
  3. Procure HACS e selecione.
  4. Marque as caixas de confirmação e clique em Enviar.
  5. A tela mostra um código de 8 caracteres. Abra github.com/login/device, entre na sua conta, digite o código e autorize o HACS.
  6. Volte ao Home Assistant e conclua. O item HACS aparece no menu lateral.

4. Instalar a integração Nexo Hub

Pelo HACS

O HACS não tem uma lista própria da Controlart: ele baixa a integração de um endereço de repositório público no GitHub, que você informa uma vez.

Endereço da integração Nexo Hub: https://github.com/fabian-rezende/nexo-homeassistant

Atalho: abrir o Nexo Hub direto no HACS (o link abre o seu Home Assistant já no repositório). Ou siga os passos:

  1. Abra HACS no menu lateral.
  2. No menu de três pontos, escolha Repositórios personalizados.
  3. Cole o endereço acima, escolha o tipo Integração e clique em Adicionar.
  4. Procure Controlart Nexo Hub na lista, abra e clique em Baixar.
  5. Reinicie o Home Assistant.

Manual (sem HACS)

  1. Copie a pasta custom_components/nexohub deste repositório para dentro da pasta de configuração do Home Assistant, ficando <config>/custom_components/nexohub.
  2. Reinicie o Home Assistant.

No Home Assistant OS, a pasta de configuração é acessível pelos add-ons Samba share ou File editor. No Docker, é a pasta do computador montada em /config.

5. Adicionar o sistema Nexo

  1. Abra Configurações → Dispositivos e serviços.
  2. Se um Nexo Hub aparecer em "Descobertos", clique em Adicionar. A descoberta acontece quando o hub pede endereço à rede, então pode demorar.
  3. Se não aparecer: Adicionar integração → Controlart Nexo Hub e digite o IP de qualquer Nexo Hub da casa. A integração encontra os outros hubs sozinha.
  4. Aparecem só os itens marcados para comando de voz, com o nome falado, já separados por ambiente.

O que é preciso no Nexo

  • Os hubs na mesma rede do Home Assistant.
  • Os itens marcados na tela "Enviar dispositivos para comando de voz" do configurador, em qualquer hub. Essas listas, as mesmas da Alexa e do Google, definem o que aparece no Home Assistant; a integração junta a de todos os hubs.
  • Cortina calibrada no configurador, para aceitar comando.
  • IP fixo ou reservado no roteador é recomendável.

Marcar ou desmarcar itens no configurador muda o Home Assistant sozinho em até 5 minutos.
